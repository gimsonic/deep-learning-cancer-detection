Abstract 
Machine Learning (ML) and Data Science are rapidly growing fields, yet their complexity often 
objects especially for beginners with limited coding experience to enter the ML field. Our 
project aims to introduce an interactive, cross-platform desktop application designed to pave a 
pathway to ML education by offering a fully graphical, no -code environment for building, 
training, and evaluating ML models. The primary objective is to create a user-friendly interface 
that enables students and educators to explore ML workflows through drag-and-drop modules 
and visualizations, without requiring prior programming knowledge. 
The application supports data preprocessing, feature engineering, model training, performance 
evaluation, and prediction analysis using open -source libraries such as PyTorch, Scikit -learn, 
and NumPy. The intended application aims to offer educational value through real -time 
graphical explanations of ML concepts, making it useful for classroom settings and self -
learners. The system architecture includes a React.js combined with an Electron.js frontend 
and a python backend, ensuring responsiveness and modular  design. By connecting intuitive 
user experience with key educational insights, the platform bridges the gap between theory and 
practical understanding, influencing users to confidently engage with modern ML concepts in 
a hands-on manner.

1. Introduction  
 
In the early 2010s, machine learning emerged as a transformative approach to solving complex 
problems, laying the groundwork for modern artificial intelligence. Over time, the field of AI 
has evolved beyond traditional machine learning algorithms, which we re primarily statistical, 
toward more specialized and abstract methodologies. However, despite these advancements, 
traditional machine learning remains an essential starting point for those new to AI, as the 
complexity of modern machine learning pipelines and workflows can be overwhelming for 
beginners. Our project aims to bridge this gap by providing a user -friendly platform that 
abstracts away the complexities of coding, offering a simple graphical interface for users to 
interact with machine learning models. Developing such a platform requires extensive research 
into both fundamental machine learning concepts and existing tools. Therefore, reviewing 
relevant literature is a crucial step in guiding the design and implementation of our application.

1.1 Motivation for the project  
The motivation for initiating this project arose from a clear and pressing gap in the current 
educational landscape of machine learning (ML). As machine learning becomes increasingly 
relevant across industries, there's a growing interest among students, educators, and self -

learners to understand its fundamentals. However, most existing ML tools and platforms are 
either heavily code-centric or designed with enterprise users in mind, making them unsuitable 
for those at the beginning of their learning journey. 
While platforms like Microsoft Azure ML Studio, Google AutoML, and IBM Watson provide 
powerful capabilities, they are primarily built for business-driven solutions and often prioritize 
deployment and performance over conceptual clarity. As a result, they c an be overwhelming 
for users who are not yet familiar with programming, data preprocessing, or model evaluation 
techniques. On the flip side, beginner -friendly tools like Google Teachable Machine offer 
simplicity but lack the depth needed to explore the fu ll ML pipeline — such as understanding 
feature engineering, exploring multiple model types, and evaluating performance with 
meaningful metrics. 
We identified a missing middle ground , a platform that is simple enough for beginners to use 
without coding, yet deep enough to allow them to meaningfully interact with the different 
stages of a machine learning workflow. This insight became the foundation for our project: to 
build an educationally focused, intuitive GUI-based application that enables users to explore, 
build, and evaluate machine learning models visually. 
By eliminating the need for programming and instead focusing on visual interactivity and 
conceptual clarity, our project aims to make ML education more accessible, engaging, and 
hands-on. This tool is especially valuable in academic environments, where stu dents can 
benefit from experimenting with real-world datasets and ML pipelines, all within a supportive, 
no-code interface that enhances understanding rather than overwhelming with complexity.

1.4 Limitations  
One key limitation we identified in existing AutoML software is the lack of comprehensive 
support for neural networks. Recognizing this as a critical gap, we designed our platform to 
include support for artificial neural networks (ANNs), allowing users to experiment with deep 
learning alongside traditional machine learning models.  Other limitations we faced could be 
listed as well. 
• Increased System Complexity 
 Integrating artificial neural networks significantly increased the complexity of the 
backend logic due to the need for layer configuration, activation functions, 
backpropagation, and training loop control. 
 
• Conceptual Depth 
 Neural networks require deeper understanding of gradient descent, weight updates, 
and hyperparameter sensitivity, making it difficult to present in a simplified, 
beginner-friendly interface without oversimplifying key concepts. 
 
• Visualization Challenges 
 Visualizing the training process (like loss curves, hidden layer activations, etc.) in 
real time while keeping the UI responsive proved technically demanding, especially 
for larger datasets or deeper models. 
 
• Limited Hyperparameter Tuning 
 Providing a no-code yet flexible interface for neural network configuration (e.g., 
optimizer choice, learning rate, batch size) was limited to a simplified version, 
restricting more advanced users.

• Discussion on the process followed during the project  
Throughout the project lifecycle, we followed a modular and iterative development strategy, 
allowing us to build, test, and refine individual components such as the Preprocessor, Model 
Builder, and Inference Engine independently. This approach ensured that  each section 
remained cohesive, testable, and educationally effective. 
The decision to implement a drag-and-drop GUI significantly enhanced usability, allowing 
students to construct ML workflows visually. During testing, even users with no prior 
exposure to Python or machine learning concepts were able to build and evaluate basic 
models successfully. This confirms the effectiveness of our visual-first concept.

• Web-Based Application Development 
One of the primary future enhancements planned for this project is the development 
of a full-featured web-based application. This will allow users to access the system 
through a browser interface without needing to install any software locally.
