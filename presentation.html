Module 1

Breast Cancer Detection — Speaker: [Member 1]

Mammogram-based screening & classification

🏗️ Model Architecture

  • ResNet50 backbone (ImageNet pretrained)
  • 3-phase progressive training
  • Grayscale input (224×224)
  • CLAHE contrast enhancement
  • Sigmoid binary classifiers

📊 Achievements

  • Trained normal-vs-abnormal classifier
  • Trained benign-vs-malignant classifier
  • Implemented sliding window for full mammograms
  • Two .keras model files deployed

📈 Progress

Model Training90%
Integration90%
Testing75%
Challenge: Small dataset causing overfitting on mammograms.
Solution: Data augmentation, label smoothing, progressive unfreezing of ResNet layers.

Lung Cancer Detection — Speaker: [Member 2]

Chest X-ray based screening & classification

🏗️ Model Architecture

  • ResNet50 with transfer learning
  • RGB input (224×224)
  • Two-stage sigmoid classifiers
  • .keras model format
  • ImageNet pretrained weights

📊 Achievements

  • Completed dataset preprocessing
  • Trained screening & classification models
  • Integrated into unified backend pipeline
  • API endpoint working end-to-end

📈 Progress

Model Training85%
Integration90%
